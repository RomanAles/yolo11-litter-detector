# Детектор мусора · YOLO11

Локальное Python-приложение для поиска мусора на фотографиях, в папках изображений и видеофайлах. Два профиля: `land` для обычных сцен и `underwater` для подводных кадров. Обучение и оценка используют только готовые TACO и TrashCan.

## Быстрый запуск

Из папки проекта запустите `run_app.bat`. Откроется окно выбора профиля, входного файла, приоритета обнаружения и папки результатов. Python запускается из отдельного окружения Miniconda `.venv`.

Команды обработки файлов и установки: [инструкция запуска](docs/USAGE.md).

## Объём текущего этапа

Подводный профиль обрабатывает только файлы. Поддержка обычной веб-камеры предусмотрена программно и требует явного запуска пользователем; физические камеры, подводный видеоканал и полевые условия в этом этапе не проверяются. Результаты на публичных датасетах не доказывают качество на новой камере.

Фотография сохраняется с рамками и JSON обнаружений. Видео сохраняется с рамками, журналом JSONL и сводкой. Видеозапись работает в CFR и не переносит звук. Демо-видео составлено из готовых кадров датасета с назначенным темпом; оно не является оригинальной записью камеры.

В улучшенной версии доступны приоритеты «Баланс», «Меньше пропусков» и «Меньше ложных рамок», а также обработка файлов по фрагментам (SAHI). Пустой Confidence использует порог выбранного приоритета. SAHI обрабатывает крупные изображения несколькими проходами и требует больше времени. Конкретные модели и пороги устанавливаются после завершения сравнения на validation.

Данные и веса находятся локально, исключены из Git. Их источники и условия использования описаны в документации; права на коммерческое использование всех исходных фотографий не заявляются.
