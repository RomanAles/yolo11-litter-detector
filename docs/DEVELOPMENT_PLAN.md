# Согласованный план реализации

Актуальная редакция от 01.11.2026: готовые датасеты, без собственных съёмок, физических камер, полевых испытаний и интеграции подводного робота. Оценка на отложенных данных и программные проверки входят в работу.

1. Подготовить структуру исходников, настроек, моделей, датасетов, результатов и документации.
2. Создать отдельное окружение Miniconda `.venv`, Python 3.11, PyTorch с CUDA, Ultralytics и OpenCV; зафиксировать версии.
3. Получить готовые TACO для обычных сцен и TrashCan для подводных сцен.
4. Преобразовать разметку в YOLO, объединить мусор в `trash`; исключить живые организмы, природные объекты и оборудование.
5. Создать train/validation/test, сохраняя связанные кадры в одной выборке; проверить точные дубликаты и границы рамок.
6. Реализовать обработку фотографии с сохранением изображения и JSON.
7. Обучить отдельную YOLO11n для каждого профиля с сохранением весов и параметров.
8. Оценить precision, recall, F1, mAP и мелкие объекты; выбрать рабочие пороги только на validation. YOLO11s — возможная последующая сравнительная итерация, если потребуется улучшение качества.
9. Добавить обработку папок и видеофайлов с журналом и корректной длительностью.
10. Предусмотреть обычную веб-камеру и ограниченный буфер, без её физического подключения.
11. Добавить простой локальный интерфейс: выбор профиля и источника, порог, запуск/остановка, результаты.
12. Подготовить воспроизводимые команды, примеры из датасетов, отчёт и ограничения.

Текущее выполнение — в [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md), команды — в [USAGE.md](USAGE.md), итоговые метрики — в [RESULTS.md](RESULTS.md).
