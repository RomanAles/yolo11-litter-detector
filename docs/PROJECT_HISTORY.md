## Исправления к старым ответам

1. Название `best.pt` не определяет архитектуру. Статический разбор конкретного checkpoint указывает на YOLOv8m; это не готовая YOLO11-модель.
2. Переименование YOLOv8-весов не превращает их в YOLO11. Для целевой модели планируется обучение YOLO11 на согласованных данных и сравнение на отложенной выборке. Официальный пример обучения: [Ultralytics YOLO11](https://docs.ultralytics.com/models/yolo11/).
3. Стандартная YOLO11 с COCO-классами не является специализированным детектором всего мусора. Например, обнаружение бутылки не определяет, выброшена ли она: это нужно закрепить в правилах разметки.
4. Репозиторий [jeremy-rico/litter-detection](https://github.com/jeremy-rico/litter-detection) действительно описывает YOLOv8 + TACO, содержит инференс, обучение и результаты с весами. Его старые команды установки нужно заменить совместимой проверенной средой.
5. Старое предложение `keremberke/yolov8m-litter-detection` не считать подтверждённой зависимостью. В чате есть ошибка загрузки; текущая веб-проверка страницы Hugging Face не дала доступного содержимого. Наличие файла с ранее предложенным именем не подтверждено.
6. Пробелы и скобки в имени файла сами по себе не объясняют ошибку. Проверять нужно реальный путь, наличие файла, текущую папку и формат checkpoint.
7. `waitKey(1000/fps)` не гарантирует правильный темп: нужно учитывать время вычислений. При записи файла важны количество записанных кадров и FPS/таймстемпы контейнера. Для live-потока нужно измерять возраст кадра и исключать накопление очереди.
8. CLAHE, резкость и TTA не гарантируют улучшение, особенно под водой. Они включаются только после сравнения качества и задержки на своих данных.

## Проверенные внешние опоры для плана

- [Ultralytics YOLO11](https://docs.ultralytics.com/models/yolo11/) — варианты моделей, обучение и COCO-предобучение.
- [Ultralytics Predict](https://docs.ultralytics.com/modes/predict/) — камера, видео, RTSP, потоковая обработка; `stream_buffer=False` отбрасывает старые кадры при отставании.
- [TACO, репозиторий авторов](https://github.com/pedropro/TACO) — источник обычного мусора в естественном окружении.
- [TrashCan, страница лаборатории авторов](https://irvlab.cs.umn.edu/resources/trashcan) — подводные изображения мусора, ROV и живых организмов; маски можно использовать для подготовки рамок при корректном преобразовании разметки. Данные преимущественно морские, поэтому перенос на пресную воду ещё требуется проверить.
- [Conda: управление окружениями](https://docs.conda.io/projects/conda/en/stable/user-guide/tasks/manage-environments.html) — отдельное окружение по пути `--prefix` и YAML-спецификация.
- [PyTorch: локальная установка](https://pytorch.org/get-started/locally/) — выбор стабильной сборки под Windows, Python и CUDA.
